# 📅 Online Appointment Booking System

## 📌 Description
The Online Appointment Booking System is a web-based application that enables users to schedule and manage appointments easily.  
It provides a simple interface for booking, updating, and canceling appointments, while ensuring a smooth and responsive user experience.  
Built with **HTML, CSS, and JavaScript**, the system demonstrates how frontend technologies can be used to create an interactive and efficient appointment management solution.

## ✨ Features
- Book new appointments
- Update or cancel existing appointments
- Search and view appointment details
- Responsive design for desktop and mobile
- Persistent data storage using localStorage

## 🛠️ Technologies Used
- **HTML** – Structure of the web pages
- **CSS** – Styling and layout
- **JavaScript** – Functionality and interactivity
